## 支持范围

- **在线推理 API**：实时获取预测结果，支持 explain 输出。  
- **批量任务**：适合定时作业或一次性回溯分析。  
- **监控告警**：提供请求指标、日志与异常通知。  
- **权限管理**：基于 API Key 的细粒度访问控制。
